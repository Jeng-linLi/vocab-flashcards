# Vocab Flashcards 單字閃卡

單檔案（零依賴、免安裝）的英文單字閃卡工具：上傳 PDF / PPTX / DOCX 自動擷取生詞，內建約 1.2 萬詞離線詞庫，線上查詞走**境內可直連的權威詞典**。

開啟方式：直接雙擊 `index.html`（`file://` 也能用），或部署到 GitHub Pages 後用網址開啟。

## 功能

- 📄 **文件取詞**：上傳 PDF / PPTX / DOCX，在瀏覽器本地解析，自動過濾基礎高頻詞與高中詞彙（可開關）
- 🔍 **線上查詞**：中文釋義（百度翻譯）、音標 / 英文釋義 WordNet / 搭配 / 同根詞 / 同義詞 / 考試標籤（有道詞典）、真人發音（英 / 美）
- 📚 **離線詞庫**：內建約 1.2 萬詞，覆蓋四六級 / 考研 / 托福 / GRE 大綱詞彙，斷網也能查詞與背誦
- 🎯 **閃卡背誦**：3D 翻卡、語音播報、隨機下一張、標記「已記住」自動移出
- 🚫 **屏蔽詞庫**：刪除或標記記住的詞自動進入屏蔽庫，下次取詞自動跳過
- 🌗 **自動深色模式**：跟隨系統 `prefers-color-scheme`
- 💾 **本地儲存**：詞庫存於 `localStorage`，不註冊、不登入

## 詞典資料源（境內直連）

| 用途 | 來源 | 介面 |
| --- | --- | --- |
| 中文釋義 | 百度翻譯 | `fanyi.baidu.com/sug`（JSONP） |
| 音標 / 英文釋義 / 搭配 / 同根詞 / 同義詞 | 有道詞典 | `dict.youdao.com/jsonapi` |
| 真人發音 | 有道詞典 | `dict.youdao.com/dictvoice` |

已知限制：`file://` 開啟時瀏覽器會攔截跨域 `fetch`（有道對 `Origin: null` 回 403），此時中文釋義改走 JSONP、發音直連 mp3，均可正常使用；有道全文資訊若取不到會自動降級，並提供有道 / 必應 / 百度詞典外鏈。

## 隱私

文件解析、詞庫、屏蔽詞全部在瀏覽器本地完成，**不上傳任何伺服器**；僅在查詞時向詞典介面送出單一單字。

## 技術筆記

- 單一 HTML 檔，原生 JS，無框架、無 build
- PDF 解析用 `pdf.js`（CDN）、PPTX / DOCX 用 `JSZip`（CDN）解壓後取文字
- 取詞後做簡易詞形還原，並過濾停用詞與高中詞表
